Philosophy

Ask less.

The evolution of computing has mostly required humans to learn how computers want to be used. Speak reverses that relationship.

You shouldn't have to know which application controls the thermostat. Which calendar contains the appointment. Which store sold the product. Where the receipt lives. Which streaming service has the movie. Which person sent the message.

You tell Speak what you're trying to accomplish. It figures out the rest.

In real homes

“What's going on today?” “Handle it.” “Find a better one.” “Where did I put that?” “Did anyone respond?” “Order what we usually get.” “Explain that.” “Keep going.” “Remember this.” “Don't let me forget.” “Tell everyone.” “Figure it out.” “Check first.” “Only tell me if it matters.” “Make the house comfortable.” “Get everything ready.” “What am I forgetting?” “What do you think?” “Thanks.”

And perhaps the most important: “Thanks.” Not because Speak needs it. Because eventually, talking to intelligence starts feeling less like operating a computer and more like sharing a space with one.
